③ 如何运行可交互完整版

本页为静态展示。完整可交互机器人（飞书 @机器人 行为模拟器，含知识补全下发闭环）需本地运行：

git clone <本仓库地址>
cd enterprise-feishu-cs-bot/demo
python app.py  →  浏览器打开 http://localhost:8000

无需安装任何第三方库（已预构建索引 demo/data/index.json，零依赖可跑）。
